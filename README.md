# CN_Project_A025_A032
A packet sniffing tool made by BCSF24A025 & BCSF24A032 in collaboration.
# Requirements
This project will only work on Windows OS, as it uses Microsoft's libraries for packet capturing.
The project requires Node.JS for running.
The application would need MinGW to work. It utilizes cpp libraries for backend working.
# Working
Move the console prompt to the project directory and then run the server.js file using "node server.js" using administrator privilages.
Click on the interface.html file and then run it, it will open in the browser and will start capturing packets as inteded.
